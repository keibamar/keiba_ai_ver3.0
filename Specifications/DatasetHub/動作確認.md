# DatasetHub (Atlas) 動作確認

Atlas はレース結果・血統・レース情報（平均値・配当）のデータセットを管理するモジュール。
Reaper（DataHarvester）からスクレイピング結果を受け取り、Oracle/Forge/Heraldにデータを提供する。
4つのサブドメイン（race_result / horse / race_info・race_returns / average_calculator）で構成され、
全テストはオフライン（通信不要、既存の `data/` 配下のCSVを参照）で実行できる。

## 実行方法

> **注意（PowerShell環境）**: `\` はbashの行継続記号であり、PowerShellでは継続記号として
> 扱われず、そのままドライブルート（`C:\`）として引数に渡ってしまう。これによりpytestが
> テスト対象を`tests/`配下に絞れず、ドライブ全体を再帰的に収集してしまう
> （`collecting 88995 items / 1066 errors`のような症状になる）。
> 1行に収まるコマンド、またはサブドメインごとに分けたコマンドを使うこと。

サブドメインごとに実行する（推奨）:

```bash
# race_result
python -m pytest tests/test_race_result_dataset_manager.py tests/test_race_result_scheduler.py -v

# horse
python -m pytest tests/test_horse_peds_dataset_manager.py tests/test_past_performance_dataset_manager.py tests/test_peds_results_dataset_manager.py -v

# race_info / race_returns
python -m pytest tests/test_race_info_dataset_manager.py tests/test_race_returns_scheduler.py -v

# average_calculator
python -m pytest tests/test_average_calculator.py -v
```

# print文の内容も表示したい場合は各コマンドに `-s` を追加

Atlas関連の全テストをまとめて実行する場合（1行のコマンド）:

```bash
python -m pytest tests/test_race_result_dataset_manager.py tests/test_race_result_scheduler.py tests/test_horse_peds_dataset_manager.py tests/test_past_performance_dataset_manager.py tests/test_peds_results_dataset_manager.py tests/test_race_info_dataset_manager.py tests/test_race_returns_scheduler.py tests/test_average_calculator.py -v
```

## テスト内容の要約

### race_result（レース結果データ）

- **test_race_result_dataset_manager.py**: 列名重複の解消（`clean_columns`）、重複行除去
  （`format_race_results_dataframe`）、文字列→int変換・コース情報抽出などの純粋関数。
  確定済みデータ（`data/race_result/05_tokyo/2024_race_results.csv`）を使った
  CSV読み込み・年別分割保存・race_id単位の保存（`save_race_result_for_race_id`）を確認。
- **test_race_result_scheduler.py**: `update_daily_race_results`（日次のレース結果取得・保存）が
  正常時・スクレイピング結果が空の場合・対象レースが無い場合の3パターンで
  正しく動作することを確認。

### horse（血統・出走馬の過去成績）

- **test_horse_peds_dataset_manager.py**: 馬名の正規化（全角・半角・記号除去）、
  血統データCSVの読み込み・保存、`make_horse_peds_datasets_from_horse_id_list`が
  既存ファイルをスキップする挙動を確認。
- **test_past_performance_dataset_manager.py**: 新旧フォーマットの過去成績データの正規化
  （`normalize_past_performance_format`）、race_idからの馬IDリスト抽出、
  レース結果から過去成績データセットを作成・更新（`update_past_performance`）、
  存在しない場合の自動生成（`ensure_past_performance_dataset`）を確認。
- **test_peds_results_dataset_manager.py**: 血統別の成績集計（複勝率等の`calc_peds_placed_rate`）、
  クラス別・総合の集計CSV生成（`aggregate_peds_results`/`aggregate_total_peds_results`）、
  血統データとレース結果のマージ（`merge_pedsdata_with_race_results`）を確認。

### race_info / race_returns（コース別平均値・配当結果）

- **test_race_info_dataset_manager.py**（最大のテストファイル、56件）:
  - 平均人気・平均馬体重・枠番別成績・平均走破タイムの集計関数（`analyze_*`系）を
    実データ（2019〜年の確定済みCSV）で検証
  - 配当結果のフォーマット変換（`format_type_returns_dataframe`、単勝〜三連単の8種別）
  - 馬名→horse_idマッピングの更新（`update_horse_name_id_map`）
  - 上記の集計結果をCSVに書き出す`update_*`系関数（週次更新で呼ばれる）
  - 書き出したCSVを読み込む`get_*_csv`系のsmokeテスト
- **test_race_returns_scheduler.py**: 配当結果データセットの新規作成・既存データへのマージ・
  スクレイピング結果が空の場合のno-op、週次/月次/年次更新関数
  （`weekly_update_race_returns`/`monthly_update_race_returns`/`make_all_race_returns`）を確認。

### average_calculator（平均タイム・タイム差の計算）

- **test_average_calculator.py**: タイム文字列（`"1:39.8"`等）をミリ秒に変換する
  `get_race_time_msec`、基準タイムとのタイム差を計算する`calc_time_diff`、
  コース・クラス別の平均タイムデータセットを作る`make_average_time_datasets`を確認。
  NaN値の扱い（欠損データに対してNaNを返す）も個別に確認。
