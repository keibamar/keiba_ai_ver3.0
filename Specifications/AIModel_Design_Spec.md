## 1. 概要

競馬AI予想モデルは「的中率重視」「回収率重視」「MAR推奨（バランス）」の3戦略を出馬表に表示する。  
各戦略は目的に応じて異なるモデルを組み合わせており、前日公開と直前公開を使い分けられる設計になっている。

## 3. 特徴量の階層構造

モデルバージョンごとに使用する特徴量が段階的に増える。

```
v3_base (60列)
  └─ 過去成績ベースの基本特徴量（着順・タイム・上りなど）

v7 = v3_base + jockey(2) + waku(2) + odds/pop(2) = 66列
  └─ 騎手コース勝率・複勝率、枠・馬番、単勝オッズ・人気

v11 = v7 + pedigree_cats(3) + v6_extra(16) + v7_extra(5) = 90列
  └─ 血統カテゴリ（父・母父・父父）、拡張過去成績16項目、斤量/休養日数/頭数など

v12 = v11 + v8_extra(7) = 97列
  └─ コーナー追走位置(5)、上がりトレンド(1)、タイム差トレンド(1)

v15 = v12 + v9_extra(7) = 104列
  └─ コース別上がり偏差(5)、コーナー比率標準偏差(1)、上がり標準偏差(1)
```

### オッズなしモデル（nodds）

`current_odds` / `current_popularity` を除外したバージョン。  
レース前日から予想を公開できるメリットがある（オッズ確定前でも使用可能）。

| モデル名 | 列数 | 対応オッズありモデル |
|----------|------|---------------------|
| v11_nodds | 86列 | v11 (90列) から odds/pop を除いたもの |
| v12_nodds | 93列 | v12 (97列) から odds/pop を除いたもの |

## 4. ブレンド方式

v7 モデルとのブレンドにより的中率・回収率を調整する。

```
blend(vXX, α) = (1 - α) × norm(s_vXX) + α × norm(s_v7)
```

- `α = 0`: vXX 単体（穴馬重視・回収率重視）  
- `α → 1`: v7 に近づく（人気馬重視・的中率重視）  
- `norm()`: 0〜1 の最小最大正規化

## 5. 3戦略の定義

### 戦略① ③ 回収率重視（前日公開可）

| | 使用モデル | α |
|--|-----------|--|
| 単勝・複勝 本命 | v12_nodds | 0（単体） |
| 3連複 5頭 BOX | v12_nodds | 0（単体） |

- オッズ不使用のため、前日から予想公開可能
- 人気に偏らず穴馬も拾いやすい
- ①と③は同一の予想

---

### 戦略② 的中率重視（直前公開）

| | 使用モデル | α |
|--|-----------|--|
| 単勝・複勝 本命 | v11 | 0.6 |
| 3連複 5頭 BOX | v15 | 0.5 |

- オッズ・人気を使用するため、レース直前（オッズ確定後）に公開
- v7 寄りのブレンドで人気馬への感度を高め、的中率を重視

---

### 戦略④ MAR推奨（バランス型）※メイン指数

| | 使用モデル | α |
|--|-----------|--|
| 単勝・複勝 本命 | v11_nodds | 0（単体） |
| 3連複 5頭 BOX | v12 | 0.4 |

- 単複本命はオッズなし（前日可）、3連複はオッズあり（直前）
- 的中率・回収率ともにバランスよく最高水準
- 出馬表のメイン表示指数として採用

## 6. 統合スコアの設計

3戦略それぞれで「単複本命スコア」と「3連複スコア」を統合し、**本命馬が必ず1位**になる指数を生成する。

```python
def _mm_strategy_score(s_tan, s_san):
    s_tan_n = norm(s_tan)
    s_san_n = norm(s_san)
    honmei  = argmax(s_tan_n)          # 単複本命馬
    combined = s_san_n.copy()          # 3連複スコアを基底
    spread = combined.max() - combined.min() + 1e-6
    combined[honmei] = combined.max() + spread   # 本命を強制1位に
    return combined
```

→ **本命馬が1位、3連複上位馬が2〜5位**に自然に並ぶ構成になる。

最終的に z-score → `score_to_index()` で 0〜100 の偏差値形式AI指数（小数1桁）に変換。

## 8. 推論フローの実装

```
make_race_card()
  └─ blended_rank_prediction()        # 旧モデル（逐次廃止予定）
  └─ multi_model_rank_prediction()    # 3戦略の統合指数を計算
       ├─ 特徴量構築（v15用104列 / nodds用102列を各馬ループで生成）
       ├─ オッズあり DF → s_v7, s_v11, s_v12, s_v15 を予測
       ├─ オッズなし DF → s_v11n, s_v12n を予測
       ├─ 3戦略ブレンド → _mm_strategy_score() で統合
       └─ score_to_index() で偏差値変換 → DataFrame 返却
            (idx_hitrate, rank_hitrate, idx_value, rank_value, idx_mar, rank_mar)
```
