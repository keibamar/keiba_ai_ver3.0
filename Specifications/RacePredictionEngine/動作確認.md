# RacePredictionEngine (Oracle) 動作確認

Oracle は Chronos から渡された race_id について、Atlas から血統・過去成績データを取得し、
LightGBM モデルで予想スコア・順位を算出するモジュール。
実装は `src/logic/prediction/race_prediction_engine.py`（予想本体）と
`src/logic/prediction/race_card_builder.py`（出馬表生成＋score/rank付与の統合窓口）。

`race_card_builder.make_race_card` のネットワークテストは DataHarvester (Reaper) の
[動作確認.md](../DataHarvester/動作確認.md) に記載済み。本ドキュメントは
race_prediction_engine（予想本体）と race_card_builder のオフライン純粋関数テストを扱う。

## 実行方法

```bash
# Oracle関連のオフラインテストを実行
python -m pytest tests/test_race_prediction_engine.py tests/test_race_card_builder.py -m "not network" -v

# print文の内容も表示したい場合は -s を追加
python -m pytest tests/test_race_prediction_engine.py -v -s
```

## 処理フロー（参考）

```
race_card_builder.make_race_card(race_id)
  ├─ netkeiba_scraper.scrape_race_card(race_id)        # 出馬表スクレイピング（Reaper）
  ├─ horse_peds_dataset_manager から血統データ取得       # peds_0/peds_1/peds_4
  └─ race_prediction_engine.rank_prediction(...)        # 予想スコア・順位を付与
       ├─ make_dataset_for_lightgbm(race_id, course_info, horse_id)  # 馬ごとに特徴量を作成
       │    ├─ 血統着度数（36列、peds_results_dataset_manager由来）
       │    └─ 過去3走分のタイム差・人気・着順（12列、get_past_race_info_data）
       │         └─ get_time_diff(race_time, course_info)  # コース別平均タイムとの差
       └─ get_lightgbm_model(place_id, race_type, course_len)  # コース別の学習済みモデルをロード
            └─ model.predict(...) でスコア算出 → rank付与
```

## テスト内容の要約

### test_race_prediction_engine.py（オフライン、全6件）

- **test_get_time_diff_returns_expected** / **test_get_time_diff_returns_zero_when_no_data**:
  `race_info_dataset_manager.get_time_diff(race_time, course_info)` —
  コース別平均タイム（`total_avg_time.csv`）とのタイム差を計算する。
  データが無いコースの場合は `[0, 0]` を返すことも確認。
- **test_get_past_race_info_data_returns_12_values**:
  `get_past_race_info_data(race_info_df)` — 過去3走分のタイム差・人気・着順を
  12個の値（3走 × 4項目）に整形する。
- **test_make_dataset_for_lightgbm_shape**:
  `make_dataset_for_lightgbm(race_id, course_info, horse_id)` — 血統着度数(36列) +
  過去3走分の特徴量(12列) = 48列・1行の特徴量データセットを作成する
  （LightGBMモデルへの入力形式）。
- **test_get_lightgbm_model_loads_from_prediction_data_path**:
  `get_lightgbm_model(place_id, race_type, course_len)` — コース別の学習済みモデル
  （`data/prediction/models/{place}/{race_type}{course_len}_lambdarank_model.txt`）を
  ロードし、特徴量数が48列の入力と一致する50（48 + 余剰2列）であることを確認。
- **test_rank_prediction_returns_score_and_rank**（エンドツーエンド、実データ）:
  `rank_prediction(race_id, horse_ids, race_info_df, waku_df)` — 16頭分の特徴量を
  作成しLightGBMで推論、`score`/`rank`列を持つDataFrameを返す。
  rankが1〜16の順列になっていることを確認。

### test_race_card_builder.py（オフライン純粋関数、5件）

- **test_parse_race_card_info_tokens** / **test_parse_race_card_info_tokens_turf_and_obstacle**:
  出馬表ページのレース情報トークンをパースする `transform.parse_race_card_info_tokens`。
- **test_fill_race_info_defaults_adds_missing_columns** / **_fills_nan_values**:
  天候・馬場状態が欠損している場合にデフォルト値（`weather="-"`, `ground_state="良"`）を
  補完する `transform.fill_race_info_defaults`。
- **test_extract_peds_for_display_returns_expected**:
  62行の血統データから表示用の3行（peds_0/peds_1/peds_4 = 父・母・父父）を
  抽出する `transform.extract_peds_for_display`。

ネットワークが必要な `test_make_race_card_returns_expected`（エンドツーエンド）は
[DataHarvester/動作確認.md](../DataHarvester/動作確認.md) を参照。
