土日 09:00  post_today_race.bat（終日実行）
     ※最終レースの30分後に自動終了
----------------------------------------
[各レース 発走20分前に繰り返し実行]

  [データ]
    - data/race_card/{日付}/{race_id}.csv  予想スコア・ランク更新
    - data/race_card/{日付}/{race_id}_info.csv  レース情報更新
    - data/race_info/horse_name_id_map.csv  馬名IDマップ更新
    - texts/race_prediction/{日付}/{race_id}.txt  予想テキスト生成

  [HTML]
    - public_html/races/{日付}/{会場}R{n}.html  出馬表更新
    - public_html/races/{日付}/index.html  日次インデックス更新
    - public_html/races/（過去7日分）index.html  リンク更新

  [投稿]
    - X: レース予想投稿
        「{年}/{月}/{日}
         {会場}{n}R {レース名} {発走時刻}

          ◎ {馬番} {馬名}
          ○ {馬番} {馬名}
          ▲ {馬番} {馬名}
          △ {馬番} {馬名}
          ☆ {馬番} {馬名}

         https://mar-keiba.com/races/{日付}/{会場}R{n}.html

         #MAR競馬予想
         #競馬予想AI
         #競馬 #競馬予想
         #{会場}競馬場」
    - メール: 同内容をGmail送信

  [前レースの処理（発走20分前のタイミングで前走の結果を取得）]
    [データ]
      - data/race_result/{race_id}.csv  前レース結果保存
      - data/race_info/returns/{race_id}.csv  前レース配当保存
    [HTML]
      - 前レースの出馬表HTML  結果・配当を反映して更新

  → レースごとに git commit + ConoHaアップロード

土日 18:00  today_race_rerturns.bat
----------------------------------------
[データ]
  - data/prediction/performance/ai_performance.csv  当日分追記
  - texts/race_returns/{日付}/{会場}_pred_score.txt  成績テキスト生成

[HTML]
  - public_html/races/{日付}/{会場}R{n}.html  全レース最終版（結果確定版）

[投稿]
  - X: 開催場別 成績投稿（開催場ごとに1投稿）
      「{年}/{月}/{日} {会場}競馬場
       MAR競馬予想 回収率
       ◎単勝回収率:xxx.x%  (的中レース:x R)
       ◎複勝回収率:xxx.x%  (的中レース:x x R)
       三連複(5頭BOX)回収率:xxx.x%  (的中レース:x R)
       #MAR競馬予想
       #競馬予想AI
       #競馬 #競馬予想
       #{会場}競馬場」

  - X: 高配当的中があれば全場まとめ投稿（1投稿）
      ※単勝/複勝 1000円以上 または 三連複5頭BOX 10000円以上
      「🏆 本日の高配当的中

       {会場}　{n}R　{レース名}
       ◎{馬名}　{人気}人気　馬番{馬番}　単勝{配当}円/複勝{配当}円

       {会場}　{n}R　{レース名}
       3連複{◎○▲など}　{配当}円

       https://mar-keiba.com/
       #MAR競馬予想 #競馬AI」
      ※高配当的中がない場合は投稿しない

========================================
【手動実行】
========================================

make_time_id_list.bat
  用途: race_time_id_listを手動更新
        （木曜の update_weekly_schedule.bat が失敗した時など）
  [データ]
    - data/race_card/time_id_list/{日付}.csv  更新

update_daily_html.bat
  用途: 出馬表HTMLを任意のタイミングで全再生成したい時
  [HTML]
    - public_html/races/{日付}/{会場}R{n}.html  全レース再生成
  → git commit + ConoHaアップロード

update_monthly.bat（月初に手動実行）
  用途: 過去月分のデータを遡って取得・補完
  [データ]
    - data/race_result/         月次取得
    - data/race_info/returns/   月次取得
    - data/horse/peds/          月次取得
    - data/horse/peds_results/  月次取得
    - data/horse/past_performance/ 月次取得
    - data/race_info/average_time.csv  更新
